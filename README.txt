# بيت عائلة نور — نسخة 3D

## التشغيل
افتح `index.html` في متصفح حديث مع اتصال بالإنترنت، لأن Three.js يتم تحميله من jsDelivr.

## التحكم
- WASD أو أزرار الهاتف للحركة.
- اسحب بالماوس/الإصبع لتدوير الكاميرا.
- اضغط على شخصية لفتح هاتفها ومحادثتها.
- زر 🌙 لتبديل الليل/النهار.
- زر 🏠 لإرجاع الكاميرا.

هذه نسخة أولى تجريبية. يمكن تطويرها لاحقًا إلى نظام غرف حقيقي، شخصيات GLB أكثر واقعية، ذكاء اصطناعي للحركة، نظام محادثات متعدد الشخصيات وحفظ الحالة.
